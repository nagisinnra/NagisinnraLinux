# NagisinnraLinux

> Lightweight. Modern. Independent.

NagisinnraLinux is an independent Linux distribution proudly developed in Japan.

Built upon the proven stability of Debian, NagisinnraLinux delivers a modern, lightweight, and customizable desktop experience designed for users of all skill levels. The project focuses on practical usability, responsive performance, and user freedom while maintaining the reliability of a mature Linux ecosystem.

Whether you are a beginner exploring Linux for the first time, a student seeking a dependable system, or an advanced user looking for flexibility and control, NagisinnraLinux aims to provide a balanced and enjoyable computing experience.

## Project Vision

NagisinnraLinux was created with a simple goal:

> Linux should be fast, practical, visually appealing, customizable, and accessible to everyone.

Rather than competing directly with established distributions, the project seeks to provide its own unique balance of simplicity, performance, customization, and usability.

Development is guided by the following principles:

- Stability
- Performance
- Simplicity
- Transparency
- Freedom
- Long-Term Growth

Every release is developed with the objective of creating a reliable and enjoyable desktop operating system for users around the world.

## Hardware Requirements

### Minimum Requirements

- CPU: 64-bit Dual-Core Processor
- Memory: 1 GB RAM
- Storage: 20 GB Available Disk Space
- Graphics: Basic Graphics Adapter
- Display: 1024×768 Resolution

### Recommended Requirements

- CPU: Dual-Core Processor or Better
- Memory: 2 GB RAM or Higher
- Storage: 32 GB or More
- Graphics: Modern Integrated or Dedicated GPU
- Display: 1920×1080 Resolution

## Installation

### Download

Download the latest release from the official SourceForge project page.

### Create Installation Media

Create a bootable USB drive using software such as:

- Ventoy
- Rufus
- Balena Etcher

### Install

1. Boot from the installation media.
2. Launch the installer.
3. Follow the on-screen instructions.
4. Reboot into your new NagisinnraLinux system.
