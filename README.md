# NagisinnraLinux

NagisinnraLinux is a lightweight Linux distribution created by **nagisinnra**.

The goal is to create a simple, fast, and minimal Linux system without unnecessary components.

## Features

- Lightweight
- Fast boot
- Minimal system
- Linux kernel based
- `apt` package management
- Server-oriented
- Simple and easy to customize

## Status

🚧 **Development**

NagisinnraLinux is currently under development.

The system and its components may change frequently.

## Philosophy

> Less software. More control.

NagisinnraLinux focuses on keeping the system simple while giving the user control over what is installed and running.
